# StrongStocks - Financial Dashboard & Stock Screener

A modern, responsive single-page React application for screening and analyzing stocks with strong fundamentals and future growth prospects. The app features a premium financial dashboard aesthetic with a sleek dark mode and neon accents, reminiscent of a modernized Bloomberg Terminal.

## Features
- **Dashboard / Market Overview:** Showcases "Fundamental Picks of the Day" and "High Growth Prospects" with beautifully styled stock cards.
- **Advanced Stock Screener:** Filter stocks by Sector, Market Cap, P/E Ratio, ROE, Debt/Eq, and Dividend Yield. Results are displayed in a clean data table.
- **Stock Detail Modal:** Click on any stock to view its 1-year price trend chart (using Recharts), fundamentals checklist, and future outlook.
- **Modern UI/UX:** Built entirely with Tailwind CSS, utilizing flexbox/grid for responsive layouts and Lucide React for consistent icons.
- **Mock Data Ready:** Data structures mirror real financial APIs (like Financial Modeling Prep or Finnhub), making it easy to swap for live data later.

## Tech Stack
- React (Vite)
- Tailwind CSS
- Lucide React (Icons)
- Recharts (Charting)

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
